# Owner-controlled balance

Individual cvars remain available. Three editable profiles are installed in `tf/cfg/sourcemod/premium_profiles/`. Queue one for the next round start from server console/root access with `sm_premium_profile cosmetic`, `balanced`, or `fun`. Append `now` to apply immediately, or use `status`/`cancel`. No profile is selected automatically, and selecting one does not rewrite your config, permissions, memberships or trials.

For persistence, add `exec sourcemod/premium_profiles/balanced.cfg` (or your chosen profile) to the **end** of `cfg/sourcemod/premium_rebuilt.cfg`. Edit the profile cfg to suit your server. These are starting points, not a claim that one set of numbers is fair on every map.

Cosmetic features (chat tags, colour, dark tint, glow and FOV) retain your existing settings in all profiles. Cosmetic mode gates gameplay separately from entitlement, so players do not lose membership or restart their trial. Profiles cover the same gameplay control set; applying one after another does not leave leftover gameplay values from the previous profile.

Key individual controls:

| Setting | Meaning |
| --- | --- |
| `premium_ammo_multiplier` | 1-10 for primary/secondary reserves and spawn ammo, including Pyro fuel; magazines stay native |
| `premium_gameplay_teams` | 0 neither, 1 RED, 2 BLU, 3 both; membership/cosmetics remain available |
| `premium_cloak_multiplier` | 1–20, ordinary and motion watches; 1 is native duration |
| `premium_deadringer_multiplier` | 1–20, Dead Ringer's post-activation cloak; activation cost/recharge/resistance stay native |
| `premium_cloak` | Master switch for both finite cloak multipliers |
| `premium_metal` | Initial Engineer spawn reserve and capacity, up to 2000; 0 disables the bonus; no automatic refill |
| `premium_sentry_limit` | 1–3 total, using normal PDA placement; extra two always max level 1 |
| `premium_pyrofly_enabled` | Enable flame flight |
| `premium_pyrofly_speed` | Horizontal flight target/cap, 100–800 |
| `premium_pyrofly_lift` | Aim-controlled climb/descent speed, 50–800 |
| `premium_pyrofly_acceleration` | Steering acceleration, 100–3000 |
| `premium_swapteam_cooldown` | 0–600 seconds between successful swaps |
| `premium_swapteam_max_difference` | Resulting destination-team advantage allowed; 0 disables this limit |

The generated `premium_rebuilt.cfg` documents the remaining speed, health, reserve ammo, throwables, jump, teleport and cosmetic settings. Owners can raise values within the supported ranges. Ownership slots, entity reserve, unsupported weapons and mode restrictions stay enforced because exceeding engine constraints can break the server. There is no metal refill and no unlimited-cloak mode. Metal already spent is never regenerated by Premium; normal pickups and resupply remain native. Applying a profile does not give a fresh one-shot spawn reward to living players.

RC8 implements saved display preferences, a benefits page, per-class/map rules, counters, shared budgets and round-start profile queues. See `RC8_SERVER_TEST.md` for all selected additions. Personal gameplay-perk opt-outs remain a possible future addition; the preferences in this version control presentation and notifications.

The source basis for native interaction checks is Valve's [cloak drain](https://github.com/ValveSoftware/source-sdk-2013/blob/master/src/game/shared/tf/tf_player_shared.cpp), [player think order](https://github.com/ValveSoftware/source-sdk-2013/blob/master/src/game/server/tf/tf_player.cpp), [Engineer PDA](https://github.com/ValveSoftware/source-sdk-2013/blob/master/src/game/client/tf/tf_hud_menu_engy_build.cpp), and [flamethrower implementation](https://github.com/ValveSoftware/source-sdk-2013/blob/master/src/game/shared/tf/tf_weapon_flamethrower.cpp). Current retail engine behavior still requires `RC6_SERVER_TEST.md` on the target server.

The former `premium_clip_multiplier` name is accepted as an alias of `premium_ammo_multiplier`. Profiles use the new name. Use one name per saved cfg to avoid ordering conflicts; live changes affect capacity, with the extra supply on the next spawn.

`addons/sourcemod/configs/premium_rules.cfg` stores class overrides and map bans. Float 0 inherits, toggle -1 inherits; explicit class values override global presets, while matching map bans always win. Root can reload with `sm_premium_rules_reload`. Defaults inherit everywhere; the example map entry matches no real map by default. Invalid rules block flight/teleport and log the failure until corrected.

RC9 airblast jump controls are documented in `RC9_SERVER_TEST.md`. It has a separate feature switch from primary-fire flight. Class `airblast` overrides inherit with -1; map flight bans block both movement perks. Native fuel cost still applies.

RC10: `premium_engineer_hud` now controls an aimed-at owner-only turret tooltip, with no always-on large text. `premium_sentry_labels` adds the compact primary/extra role. Team budget details remain available in the benefits page.

All buildings share six native ownership slots per Engineer. A teleporter entrance and exit each use one slot; three pairs leave no sentry/dispenser slots. The new type caps are separate cvars, not a promise that every cap can be filled simultaneously. See `RC11_SERVER_TEST.md`.

RC12 feature access is configured separately in `premium_features.cfg`. Public/user grants do not change the profiles or their numeric limits. A grant still obeys the chosen profile, class/map/team gates and six-building limit. `premium_trial 0` disables trial entitlement without stopping independent grants. See `RC12_SERVER_TEST.md`.

The RC13 points economy is independent of these profiles and off by default. Prices, durations and lifetime points-trial limits are configurable. Purchased access obeys the profile/class/map/team settings; disabling a feature does not pause its rental clock or refund points. See `RC13_SERVER_TEST.md`.
